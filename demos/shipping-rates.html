<shipping-rates> Web Component

This component has to be aimed at an API end point that handles the actual carrier interactions. The component sends an address and array of item details (weight, dimensions, count) – and expects to receive a rate or list of rates.

The Netlify function provided in this repo demonstrates an API endpoint for calculating USPS rates.
