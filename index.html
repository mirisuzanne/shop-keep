Features

  • Shop-keep saves and updates the shopping cart
  • Buttons can use commandfor to send the cart a variety of commands – such as adding, incrementing, or removing items.
  • Cart-control form fields can be used to edit the properties of a product in the cart – such as the count, note, or name-your-price offer.
  • Shipping-rate form (along with an API endpoint) can be used to estimate USPS shipping rates for a single item, or all items in the cart.
